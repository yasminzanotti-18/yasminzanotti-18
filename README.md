## 02 // PROJETO EM DESTAQUE

<div align="center">

<img src="https://capsule-render.vercel.app/api?type=rect&color=F1E8D9&height=100&section=header&text=AgriFarm&fontSize=42&fontColor=79513B&desc=Gerenciamento%20Inteligente%20de%20Ra%C3%A7%C3%A3o%20nas%20Fazendas&descSize=13&descAlignY=75" width="100%" />

</div>

O **AgriFarm** é um projeto de gerenciamento inteligente de ração nas fazendas, criado para facilitar o controle de informações e contribuir para uma gestão mais eficiente.

### O que desenvolvi no projeto?

- Cadastro e gerenciamento de fazendas e animais.
- Controle de estoque e tipos de ração.
- Acompanhamento do consumo de ração.
- Relatórios para análise de informações.
- Integração com sensores e dispositivos IoT.
- Organização de dados para apoiar a tomada de decisões.
